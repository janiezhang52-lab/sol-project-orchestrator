# Security

[简体中文](SECURITY.md) | English

Do not disclose unpatched vulnerabilities, personal information, credentials, or local state in a public issue.

Use **GitHub Private Vulnerability Reporting** on the repository's [Security page](https://github.com/janiezhang52-lab/sol-project-orchestrator/security) if the “Report a vulnerability” option is available. If it is unavailable, do not post sensitive details publicly; ask the maintainer to confirm a private reporting channel without including the vulnerability details. The commercial licensing email is not a security-reporting channel.

Include the affected version, a minimal reproduction, actual impact, and possible mitigations. The maintainer reviews reports as time permits; there is no guaranteed response time or SLA.
