# Support

[简体中文](SUPPORT.md) | English

Use [GitHub Issues](https://github.com/janiezhang52-lab/sol-project-orchestrator/issues) for reproducible bugs and usage questions. The initial support plan uses Issues rather than Discussions. Include the version, operating system, minimal steps, and sanitized error information.

Do not post credentials, local ledgers, complete conversation transcripts, or logs containing personal paths. This community project provides no SLA, fixed response time, or guarantee of compatibility with every Host environment.

Start with the [installation and usage guide](README.en.md), [product contract](docs/PRODUCT-CONTRACT.en.md), and [validation scope](provenance/PUBLIC_PROVENANCE.en.md).
